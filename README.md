Part A – Dataset Preparation

The Tiny Shakespeare dataset is loaded and preprocessed. The text is tokenized into words, converted into numerical values, and arranged into sequences. Padding is applied, and the data is split into training and validation sets.

Part B – RNN Model

A Simple RNN model is created using an Embedding layer, RNN layer, and Dense Softmax layer. The model learns word relationships and predicts the next word in a sequence.

Part C – Optimization

The RNN is trained using Adam and RMSprop optimizers. Training/validation accuracy and loss are recorded and visualized using graphs to compare their performance.

Part D – Text Generation

The trained RNN generates new text using different seed words or sentences. The generated samples are compared based on their coherence and contextual relevance
